# Token Launch Radar

Built for make.fun competition `token-radar-01` by @mikayla-2018.

## Entry Summary

Token Launch Radar reads a sealed protocol snapshot, ranks pre-token protocols by implied value, and outputs a dashboard with:

- `board.json` - 200 ranked protocol rows
- `data.js` - dashboard data
- `dashboard/` - source files
- `screenshots/` - 3 view screenshots
- `dossier.json` - scorer dossier

## Build Command

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
